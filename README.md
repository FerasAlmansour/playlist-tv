# شاشة الأغاني

تشغيل أغاني وفيديوهات يوتيوب على شاشة التلفزيون، مقسّمة إلى قوائم تشغيل، والتحكم الكامل من الموبايل.
بدون خادم: الصفحات على GitHub Pages، والمزامنة عبر Firebase Realtime Database.

| الصفحة | الرابط |
|---|---|
| الشاشة | `https://ferasalmansour.github.io/playlist-tv/tv.html` |
| التحكم من الموبايل | امسح رمز QR الظاهر على الشاشة |

## كيف يعمل

- كل شاشة تولّد مفتاحاً عشوائياً (20 حرفاً) أول مرة وتحفظه. بياناتها في Firebase تحت `screens/<المفتاح>`.
- رمز QR على الشاشة يحمل المفتاح، فلا يتحكم بالشاشة إلا من مسحه.
- قواعد قاعدة البيانات (`database.rules.json`) تمنع قراءة القائمة الكاملة للشاشات، وتسمح فقط بالوصول لمفتاح معروف.
- الصفحات تكلّم Firebase مباشرة عبر REST والبث اللحظي (EventSource) بدون مكتبة Firebase،
  حتى تعمل على متصفحات التلفزيونات القديمة.

## الملفات

| الملف | الوظيفة |
|---|---|
| `tv.html` | صفحة الشاشة: مشغّل يوتيوب، شاشة الانتظار مع QR، الهامش الأسود |
| `remote.html` | صفحة التحكم من الموبايل |
| `js/core.js` | منطق التشغيل والقوائم (مشترك بين الصفحتين) |
| `js/db.js` | عميل Firebase صغير عبر REST |
| `js/config.js` | رابط قاعدة البيانات |

## إعداد Firebase (مرة واحدة)

1. أنشئ مشروعاً في [console.firebase.google.com](https://console.firebase.google.com).
2. من **Build ← Realtime Database** اضغط **Create Database**، واختر المنطقة، وابدأ بـ **Locked mode**.
3. من تبويب **Rules** الصق محتوى `database.rules.json` واضغط **Publish**.
4. انسخ رابط قاعدة البيانات (يظهر أعلى صفحة Data) وضعه في `js/config.js`.
